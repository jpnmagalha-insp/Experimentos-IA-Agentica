# Brand — nutri.

Diretrizes de identidade e posicionamento de marca.

## Tom de Voz e Linguagem

A `nutri.` fala como alguém que entende de nutrição mas não quer te dar uma aula — é direto, acolhedor e sem julgamento.

**Princípios:**

- **Preciso, não clínico.** Use números e dados quando importam; evite jargão técnico desnecessário.
- **Acolhedor, não condescendente.** O app apoia, não prescreve. Nunca culpe ou pressione o usuário.
- **Conciso.** Frases curtas. Sem rodeios. O usuário está no meio de uma refeição.
- **Humano.** Erros têm mensagens honestas. Conquistas merecem reconhecimento genuíno, não emojis excessivos.

**Exemplos de tom:**

| Evitar                                       | Preferir                          |
| -------------------------------------------- | --------------------------------- |
| "Você ultrapassou sua meta calórica diária!" | "Você foi além da meta de hoje."  |
| "Insira os dados antropométricos"            | "Qual é a sua altura?"            |
| "Erro ao processar sua solicitação."         | "Algo deu errado. Tente de novo." |
| "Parabéns!! 🎉🎉 Meta atingida!!"            | "Meta batida hoje."               |

## Identidade Visual

### Marca

**`nutri.`** — sempre minúsculo, sempre com ponto final. O ponto é parte do nome e aparece na cor terracota (`#D97757`) em qualquer aplicação sobre fundo claro.

### Filosofia visual

Quente, acolhedor, preciso. A paleta se apoia em **terracota + creme** — deliberadamente distante do clichê wellness verde-menta. A marca transmite seriedade sem frieza, e calor sem infantilidade.

### Tipografia

| Papel   | Fonte                              | Uso                                       |
| ------- | ---------------------------------- | ----------------------------------------- |
| Display | **Newsreader** (serif)             | Logotipo, números hero (kcal em destaque) |
| UI      | **Plus Jakarta Sans** (sans-serif) | Todo o restante da interface              |

- Newsreader confere autoridade e caráter orgânico aos números — faz o dado parecer importante.
- Plus Jakarta Sans garante legibilidade em tamanhos pequenos e hierarquia clara.
- Nunca misture uma terceira família tipográfica.

### Paleta de Cores

| Nome            | Hex         | Uso                                                                                                  |
| --------------- | ----------- | ---------------------------------------------------------------------------------------------------- |
| Terracota       | `#D97757`   | Cor primária. Acento, não preenchimento. Ações principais, destaque do logotipo, indicadores ativos. |
| Paper           | `#FAFAF7`   | Background principal. Branco quente, nunca branco puro.                                              |
| Line            | _(definir)_ | Bordas, separadores, anel do logotipo. Tom neutro escuro sobre paper.                                |
| Texto principal | _(definir)_ | Alto contraste sobre `#FAFAF7`. Mínimo 4.5:1 (WCAG AA).                                              |

> A terracota é usada como acento — ela chama atenção onde importa. Evite usá-la em grandes áreas preenchidas.

### Logotipo

O logotipo é composto por dois elementos:

1. **Logo-mark:** anel circular com leve rotação (−8°) e um arco em terracota sobreposto, mais um ponto sólido terracota no quadrante superior direito. Evoca precisão, ciclo e vitalidade sem recorrer a símbolos óbvios de saúde.
2. **Logo-name:** `nutri.` em Newsreader, `font-size` base de 32px (versão padrão) ou 44px (versão hero). `letter-spacing: 1px`.

**Variações:**

| Variação                    | Quando usar                                        |
| --------------------------- | -------------------------------------------------- |
| Logo completo (mark + nome) | Preferencial em telas de login, splash, onboarding |
| Só o mark                   | Ícone do app, favicon, badge                       |
| Só o nome                   | Cabeçalhos internos onde o mark já aparece próximo |

**Regras de uso:**

- Nunca rotacionar o nome.
- Nunca alterar as cores do mark independentemente — terracota e line sempre juntos.
- Área de proteção mínima: metade da altura do logo-mark em todos os lados.
- Não usar sobre fundos coloridos sem validar contraste.

## Guias de Uso em Diferentes Contextos

### App (iOS / Android)

- Seguir as diretrizes de acessibilidade: contraste mínimo 4.5:1, toque mínimo 44×44pt, suporte a Dynamic Type.
- Terracota reservada para: botões de ação primária, indicadores de seleção ativa, o ponto do logotipo.
- Backgrounds alternativos (cards, modais) devem permanecer dentro da família creme/neutro quente.

### Web / Landing page

- Logo sempre linka para a home.
- Manter a mesma tipografia e paleta — sem adaptações "mais modernas" para web.

### Comunicação (e-mail, push, in-app)

- Tom idêntico ao definido acima.
- Push notifications: máximo de uma linha. Sem ponto de exclamação.
- E-mails transacionais: sem imagens decorativas; só dado e ação.

### Materiais externos (apresentações, press)

- Usar sempre os arquivos de logo fornecidos — nunca recriar à mão.
- Fundo preferencial: `#FAFAF7`. Alternativa escura: validar contraste do mark antes de usar.
